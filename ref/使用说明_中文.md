# scomplex

其他语言：[introduction_en.md](introduction_en.md) · [Mode_d'emploi_français.md](Mode_d'emploi_français.md) · [使用説明_日本語.md](使用説明_日本語.md)

scomplex 是一套在三种相关的二维代数上做运算的小库：普通复数、分裂复数（双曲数）和对偶数。乘法公式处处相同，用标量参数 `system` 选择当前代数。

同一套代数有三个语言移植：

| 语言 | 文件 | 如何选择代数 |
|---|---|---|
| C | `scomplex.h`、`scomplex.c` | 显式传入 `double system` |
| C++ | `scomplex.hpp`、`scomplex.cpp` | `complex<_Tp>::set_system` / `get_system` |
| Haskell | `Scomplex.hs`（模块 `SComplex`） | 显式传入 `Double`，多数函数的第一个参数 |

三份移植应彼此一致，并与原版 C++ 源文件 `scomplex_no_throw.hpp` 一致。原版是「写进标准库」的叠层：放在 `std::complex::experimental::zhangzl` 里，靠叠加普通标准头文件自洽，并且 **不** `#include <complex>`，以免和 `std::complex` 冲突。这里的 C++ 移植保留这一叠层。相对画板用的 `no_throw` 构建，唯一有意的差别是错误处理：失败路径会真正报错，而不是 catch 之后吞掉。

超越函数 **不是** `std::sin` / `atan2` / `std::polar`。那些公式只对普通复数（`i² = −1`）成立。这里用库自己的乘法来实现（幂级数、牛顿迭代、算术–几何平均）。

`scomplex.cpp.h` 是误命名的头文件，已经删除。C++ 调用方包含 `scomplex.hpp`，并且必须 **链接** `scomplex.cpp`。

接受用户 functor 的模板（`differential`、`invert`、`integral`）不能放到 `scomplex.cpp`：functor 类型只在调用方的翻译单元里才知道。类模板和其他自由函数模板出于同一原因留在头文件里。

## 三种代数

一个值始终是一对实分量 `(x, y)`。乘法为

```
(x, y) * (u, v) = (x u + system * y v,  x v + y u)
```

| `system` | 代数 | 虚单位 | 平方 |
|---|---|---|---|
| `−1` | 普通复数 | `i` | `i² = −1` |
| `+1` | 分裂 / 双曲 | `j` | `j² = +1` |
| `0` | 对偶 | `ε` | `ε² = 0` |

C 宏：`SC_SYSTEM_COMPLEX`、`SC_SYSTEM_SPLIT`、`SC_SYSTEM_DUAL`。

C++ 默认 `complex<double>::_system = −1`。在读取该静态成员的运算之前，用 `complex<double>::set_system(+1)` 或 `set_system(0)` 切换。Haskell 的 `defaultSystem` 是 `−1`。

用于定义域检查的（代数）范数是

```
norm(z) = x² − system * y²
```

`norm_norm(z) = x² + y²` 是欧氏长度的平方，**不**依赖 `system`。按二的幂缩放（`shift_left` / `shift_right`，C 的 `sc_shl` / `sc_shr`）用 `norm_norm`，好让牛顿 / AGM 的自变量落在合适区间。

## 错误处理

错误是真实的，不会被丢掉。

| 移植 | 机制 |
|---|---|
| C | `sc_last_error`（`SC_OK`、`SC_ERR_DIV_BY_ZERO`、`SC_ERR_OVERFLOW`、`SC_ERR_DOMAIN`、`SC_ERR_CONVERGENCE`、`SC_ERR_INVALID`）。`sc_set_error` 写入，`sc_peek_error` 读取，`sc_get_error` 读取并清零，`sc_error_string` 把错误码变成文本。 |
| C++ | `throw`。自定义类型 `complex_error`、`complex_division_by_zero`、`complex_overflow`、`complex_domain_error`、`complex_convergence_error` 继承 `std::runtime_error`。部分原版路径仍抛 `std::domain_error` 或 `std::invalid_argument`（字符串构造、`sqrt` 定义域）。 |
| Haskell | `throw` `ComplexError`（`DivisionByZero`、`Overflow`、`DomainError String`、`ConvergenceError`、`InvalidFormat String`）。 |

`sc_last_error` 是进程内唯一对象（定义在 `scomplex.c`）。C++ 的 `_system` 和 `print_number` 是类模板的静态成员，因此按类型一份、进程共享，并且不是线程安全的。没有外部锁时，不要在同一类型上并发调用 C 或 C++ 库。

构造一对分量时检查溢出：非有限分量，或绝对值超过 `max/2`（C：`DBL_MAX / 2`）。除零条件是 `|denominator| < ε`。

## 算术与比较

加法、减法、取负、共轭不用 `system`。乘法、除法、取余要用。

C 名称：`sc_add`、`sc_sub`、`sc_mul`、`sc_div`、`sc_mod`、`sc_neg`、`sc_conj`，以及与实数混算的辅助函数（`sc_add_real`、`sc_mul_real`、`sc_div_real`、`sc_real_div` 等）。

C++ 在 `complex<_Tp>` 上用普通运算符，包括 `+=`、`*=` 等。取余对商做 `round_left`（`x - round(x)` 一类的小数部分），再乘回去。

比较是字典序：先实部后虚部。C：`sc_equal`、`sc_less` 等。Haskell：只有派生的 `Eq`，没有 `Ord` 实例。

**`abs` 是按分量取绝对值**，结果是 `|x| + |y| i`，不是模长。欧氏长度是 `sc_modulus` / `sqrt(norm_norm(z))`。这与原版一致。

---

## 位运算与指数移位

IEEE-754 位技巧来自原版，用来做廉价的二的幂缩放：

- C：`sc_flnot` / `sc_flor` / `sc_fland` / `sc_flxor`（float），`sc_dblnot` / `sc_dblor` / `sc_dbland` / `sc_dblxor`（double），`sc_shift_left` / `sc_shift_right`（对指数域加减）。
- C++：`digital_not` / `digital_or` / `digital_and` / `digital_xor`，`shift_left` / `shift_right`，`round_left`，`medium_mod`。
- Haskell：`shiftLeft` / `shiftRight`，通过 `scaleFloat`。

对有限非零 double，`shift_left(a, n)` 就是 `a * 2ⁿ`，实现方式是把 `n` 加到指数位上。零仍是零。这些 **不是** C 的整数移位。

---

## 字符串解析

去掉空白后接受的形式：

- 只有实部：`3`、`-2.5`
- 只有虚部：`i`、`+i`、`-i`
- 两者都有：`3+4i`、`3-4i`、`3+i`

C++ 在 `std::string` 构造函数里用正则，不匹配就抛 `std::invalid_argument`。C 的 `sc_from_string` 写入 `SC_ERR_INVALID` 并返回零。Haskell 的 `fromString` 抛 `InvalidFormat`。

## 初等函数

这些函数都接受 `system`（C / Haskell）或读取 `_system`（C++）。

### 平方根、立方根、整数次根

先用指数移位把 `|z|` 收到 `[0.5, 2]`，再牛顿迭代。

- 实部非负且虚部为零的平方根（以及实立方根）走宿主的 `sqrt` / `cbrt`。
- 若 `norm(z) < 0`，**平方根是定义域错误**（普通负实数的 `norm = x² ≥ 0`，因此允许；分裂的 `sqrt(j)` 不允许）。
- 对偶 `sqrt(−1)` 的 `norm = 1`，因此 **不是** 定义域错误。迭代可能给出极大的虚部。这是原版行为。

初值：右半平面用 `1`；平方根否则用 `exp(i π / 6)`（或其共轭）；立方根用 `exp(i π / 9)`。

### 指数

自变量为实数时走宿主 `exp`。若 `norm_norm(z) > 1`，用 `exp(z) = exp(z/2)²`（库自己的乘法）。否则对虚部做 Horner 级数，再乘 `exp(real)`。默认 20 项。

推论：普通系统 `exp(i π) ≈ −1`；分裂系统 `exp(j) = cosh 1 + j sinh 1`；对偶系统 `exp(ε) = 1 + ε`。

`polar(ρ, θ)` 是 `exp(log ρ + θ · unit)`，用的是这里的 `exp`，不是 `std::polar`。

### 对数与辐角

`z = 0` 或 `norm(z) < 0` 时为定义域错误。正实数走宿主 `log`。否则用指数移位缩到一个带子里（同时加上 `ln 2`），再用 AGM 恒等式：

```
log(z) ≈ (π/2) * (1/AGM(1, q) − 1/AGM(1, z q))
```

其中 `q` 很小。默认外层 40 步、AGM 8 步。`arg(z)` 是 `imag(log(z))`。

### 余弦与正弦

余弦：实部对 `2π` 取模，再对半直到 `norm_norm ≤ 1`（`cos 2α = 2 cos²α − 1`），然后级数。默认 20 项。

**正弦是 `cos(π/2 − z)`**，与原版相同，不是另一套级数。

`tan`、`cot`、`sec`、`csc` 是它们的比。

### 双曲函数

```
sinh z = (exp(z) − exp(−z)) / 2
cosh z = (exp(z) + exp(−z)) / 2
```

以及通常的比值。反双曲是常用的 log/sqrt 恒等式，用本库的 `log` 和 `sqrt` 求值。

### 幂

整数实指数用二进制幂（`sc_pow_int`）。否则 `exp(log(base) * exponent)`。复次根是 `exp(log(base) / exponent)`；指数为整数时用牛顿 `root`。

## 反三角函数

没有闭形式的 `asin` 级数。`acos` 是对 `cos` 做牛顿反演（`invert` / `sc_invert`）。其余是建立在它上面的恒等式：

```
asin(z) = π/2 − acos(z)
atan(z) = acos(1 / sqrt(z² + 1))
acot(z) = π/2 − atan(z)
asec(z) = acos(1/z)
acsc(z) = π/2 − asec(z)
```

**`atan(−1) = +π/4`**，不是 `−π/4`。该恒等式在负实轴上丢掉了符号。这是原版，不是移植错误。

`invert` 每步对目标函数做两次微分（两次有限差分），当更新量的按分量 `abs` 低于 `10⁻³` 时停下，或达到 `max_iterations`（默认 100）。若微分抛出，C++ 再抛 `complex_convergence_error`。

---

## Gamma 与 beta

Weierstrass 乘积，默认 **100 000** 次迭代（原版）。`Re(z) < 1/2` 用反射公式，`Re(z) > 1` 用递推。实轴上的非正整数是定义域错误。`beta(a, b) = Γ(a) Γ(b) / Γ(a+b)`。

---

## 微积分

在 `a` 处的有限差分导数：

```
d_real = (f(a + δ) − f(a)) / δ
d_imag = (f(a + i δ) − f(a)) / (i δ)
```

若两者不一致（相对差的按分量 `abs` `> 10⁻³`），则视为不可复可微：C 写入 `SC_ERR_DOMAIN`，C++ / Haskell 抛出。否则结果取平均。默认 `δ = 10⁻⁶`。

从 `a` 到 `b` 的积分是左黎曼和，步长 `δ (b − a)`，循环条件是 `δ · k ≤ 1`。默认 `δ = 10⁻⁶`。

C 回调类型是 `sc_func_s`：`sc_complex (*)(sc_complex, double system)`。C++ 和 Haskell 接受任意兼容的 functor / 函数。

---

## 超运算与 M / T / B

`hyper_xexp(z, n)` 把 `exp` 套用 `n` 次（若 `n < 0` 则套用 `log` `|n|` 次），再乘以 `z`。

`hyper_omega(z, n)` 在 `n ≥ 0` 时是对 `z` 的牛顿反演（`invert`）；负的 `n` 对 `hyper_omega(z, −n)` 再套若干次 `exp`。

C 在 `sc_hyper_omega` 调用 `sc_invert` 期间，把当前的 `n` 和 `system` 放在文件内静态变量里。这是 C API 不可重入的另一原因。

`M`、`T`、`B`（以及 C++ 对数组的批量重载）是原版 Mandelbrot 风格的映射：`M(a, c, f, L)` 按 `L` 取 `a − f(a) + c` 或 `f(a) + c`；`T` 先取共轭；`B` 先按分量 `abs`。`sc_square` / C++ 默认 `pow(x, 2)` 是通常的二次项。

## C++ 叠层细节

```cpp
#include "scomplex.hpp"
using namespace std::complex::experimental::zhangzl;

complex<double>::set_system(-1.0);
complex<double> z(2.0, 1.0);
auto w = exp(z);
complex<double> i("i");
```

- 命名空间：`std::complex::experimental::zhangzl`。
- **不要** 像对待 `std::complex` 那样 `#include <complex>`；本头已经在嵌套的 `std::complex` 命名空间里定义了 `complex`。
- MSVC 必须加 `/utf-8`。源文件是 UTF-8；不加该标志可能出现 C4819，甚至把 `_system` 的定义吃掉导致 LNK2019。
- 链接 `scomplex.cpp`。否则 `shift_left` / `shift_right` / `round_left` / `medium_mod` 无法解析。
- MSVC 下 `COMPLEX_ALWAYS_INLINE` 是 `__forceinline`，与部分运算符上的 `inline` 叠用会出 C4141，不影响链接。
- 负范数的 `sqrt` 抛带 `"Square root of non-positive number"` 的 `std::domain_error`，与原版相同，不是 `complex_domain_error`。

## C 细节

```c
#include "scomplex.h"

sc_complex a = sc_make(2.0, 1.0);
sc_complex b = sc_make(1.0, 3.0);
sc_complex p = sc_mul(a, b, SC_SYSTEM_COMPLEX); /* -1 + 7i */
sc_error_t e = sc_get_error();
```

编译并链接 `scomplex.c`。C11 即可。为从 C++ 调用 C API 提供了 `extern "C"`。

`sc_get_error` 会清掉标志。若只需查看、不要消费，用 `sc_peek_error`。

## Haskell 细节

```haskell
import qualified SComplex as SC

let z = SC.fromRealImag 2 1
    w = SC.multiply SC.defaultSystem z (SC.fromRealImag 1 3)
```

多数运算把 `system` 放在第一位。`add` / `subtract` / `conjugate` / `fromString` / `abs` 不用，因为它们与系统无关。

Prelude 的 `sqrt`、`exp`、`log`、`sin` 等被 hiding；请用 `SComplex`，或 `qualified Prelude as P`。

## 常量

C 函数 `sc_pi`、`sc_2pi`、`sc_pi_2`、`sc_pi_3`、`sc_e`、`sc_sqrt2`、`sc_sqrt1_2`、`sc_cbrt2`、`sc_cbrt1_2`。C++ 在 `complex<_Tp>` 上的静态量（`pi()`、`e()` 等）以及 `i()`。Haskell 局部名 `piVal`、`sqrt2` 等。

`sc_exp_i_pi_1_6` / `sc_exp_i_pi_1_9` 是牛顿初值 `exp(i π / 6)` 和 `exp(i π / 9)`。

## 需要保留的原版语义

若按教科书主值打分，这些看起来像 bug。它们就是原版库：

1. `abs` 按分量，不是模长。
2. `sin(z) = cos(π/2 − z)`。
3. `atan(−1) = +π/4`。
4. 对偶 `sqrt(−1)` 不是定义域错误（`norm = 1`）；值可以极大。
5. 分裂 `sqrt(j)` **是** 定义域错误（`norm = −1`）。
6. Gamma 用 100 000 项 Weierstrass 乘积。
7. 有限差分反演以 `10⁻³` 为停止条件，因此反三角比较粗。

## 编译（MSVC / GHC）

源文件是 UTF-8。

```text
cl /utf-8 /std:c11 scomplex.c your.c
cl /utf-8 /std:c++17 /EHsc scomplex.cpp your.cpp
ghc -i. YourMain.hs
```

GCC/Clang 对应做法：把 `scomplex.c` 或 `scomplex.cpp` 与调用方一起编译；C++ 需要异常（`-fexceptions`，通常默认打开）。C++ 头使用 MSVC/GCC 的对齐与预取宏，运行时不要求 SIMD。

## 建议的源码阅读顺序

1. 乘法与 `norm` —— 整个设计就是这一份乘法。
2. `exp` / `log` / `sqrt` —— `system` 如何真正改变分析。
3. 先 `cos` 再 `sin` —— 那个归约恒等式。

5. `scomplex.c` 里的错误路径，对比 `scomplex.hpp` 的 throw，对比 `Scomplex.hs` 的 `throwError`。
